Connect Odoo to K-Message

Three steps. Install, paste a key, switch on the first message. The rest happens by itself — including writing your WhatsApp templates and submitting them to Meta.

1Install the app
Apps → Update Apps List, search for K-Message Connector, press Activate.
You install one app. The parts for Invoicing, Sales and Inventory attach themselves if you have those apps, and stay away if you do not.
Nothing sends yet. Installing changes what Odoo can do, not what it starts doing.
2Connect your account
Open K-Message → Configuration → Connect and paste two things:
  • K-Message URL — https://api.k-message.kerneltics.com
  • Private token — in K-Message: Settings → API Keys, starts with whm_
Press Connect. It tells you who the token belongs to and what it may do — before anything is written. Then choose what it should set up:
Write the templates for meCreates the WhatsApp messages in Arabic and submits them to Meta. Approval usually within minutes.
Let K-Message call this OdooSubscribes to WhatsApp events, so replies and delivery news come back.
Teach the assistant to ask OdooPublishes Odoo's capabilities as tools for the assistant.
Issue a token for K-MessageThe key K-Message uses when it asks Odoo about a customer.
Press Set it up, and you get a summary, line by line, of what happened.
The issued token is shown once. Odoo keeps only a fingerprint of it — copy it now, or issue another later from the Tokens screen.
3Switch on the first message
Open K-Message → Configuration → Automations → New:
  • When — pick the trigger: an invoice is posted, an order confirmed, a delivery validated.
  • Send — pick the template, such as odoo_invoice_ready.
  • Placeholders — one row per {{n}}: the customer's name, the number, the amount.
  • Switch it on. New rules start off.
Post an invoice. Within two minutes the message arrives with the PDF, and the invoice's own chatter says so.
Try it safely first: tick Practice mode on the connection. Every message is prepared and recorded, and nothing leaves.
Before you start: Odoo 17 or 18, wkhtmltopdf installed (Odoo prints the invoice PDF with it), and a K-Message token.
To let the assistant ask Odoo, Odoo must be on an address the internet can reach — sending invoices does not need that.
