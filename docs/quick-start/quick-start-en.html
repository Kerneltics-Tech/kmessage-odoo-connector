Connect Odoo to K-Message

Install, paste a key, post an invoice. Everything between is done for you — the WhatsApp templates, the rules that use them, and the connection back.

1Install the app
Apps → Update Apps List, search for K-Message Connector, press Activate.
One app. The parts for Invoicing, Sales and Inventory attach themselves if you have those apps. Nothing sends yet.
2Connect your account
Open K-Message → Configuration → Connect and paste your private token from K-Message (Settings → API Keys, starts with whm_). There is nothing else to fill in.
Press Connect. One button, and it does the rest:
The templatesWhatsApp messages in Arabic, submitted to Meta, approved in minutes.
The rules"Send the invoice when it is posted" arrives on; order, quotation and delivery arrive off.
The other directionRegisters itself with K-Message and publishes the assistant's tools — nothing to send anyone.
The tokenThe key K-Message uses when it asks Odoo about a customer.
The issued token is shown once — copy it now, or issue another later. To pick and choose instead, Choose what it sets up sits beside the button.
3Post an invoice
That is all: Send the invoice when it is posted was switched on in step 2. Post an invoice and the message arrives within two minutes, PDF and all.
The other rules sit in Configuration → Automations, off. Read one, flip its toggle. Delete one by mistake and Restore the default rules puts it back without touching your own.
Try it safely first: tick Practice mode on the connection — every message is prepared and recorded, and nothing leaves.
Before you start: Odoo 17 or 18, wkhtmltopdf installed (Odoo prints the invoice PDF with it), and a K-Message token. To let the assistant ask Odoo, Odoo must be on an address the internet can reach — sending invoices does not need that.
